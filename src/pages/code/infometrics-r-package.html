The infometrics package is available on CRAN.

Installation Instructions

Install from CRAN (recommended)

  1. Install the infometrics package directly from CRAN.

    install.packages("infometrics")

  2. Activate the infometrics package.

    library(infometrics)

  3. Access help files.

    help(package="infometrics")

Install from GitHub

  1. Install the devtools package.

    install.packages("devtools")

  2. Activate the devtools package.

    library(devtools)

  3. Install the infometrics package.

    install_github("ganba/infometrics")

  4. Activate the infometrics package.

    library(infometrics)

  5. Access help files.

    help(package="infometrics")
